# Persistent Chat and Ownership Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give ADP a persistent product-owned terminal chat experience, mandatory final result cards, and no worker-provider attribution in user-facing output or task artifacts.

**Architecture:** Add a compact transcript/result model to `TerminalUI`, preserve Prompt Toolkit composer/footer behavior, centralize final task rendering in `AdvertpreneurCLI`, and use one narrow ownership module for instructions, response normalization, and changed-text-file checks.

**Tech Stack:** Python 3.10+, Prompt Toolkit, pytest/unittest.
